Sales Data Analytics Dashboard

Project Overview

This project analyzes retail sales data to identify key business insights such as revenue trends, regional sales performance, and top-selling product categories.

The dataset was cleaned and analyzed using Python, and an interactive dashboard was built to visualize the results.

Tools & Technologies

- Python
- Pandas
- Microsoft Power BI
- Jupyter Notebook

Dataset

The project uses the Sample Superstore retail dataset, which contains sales transactions including order dates, regions, product categories, sales revenue, and profit information.

Key columns in the dataset:

- Order Date
- Region
- Category
- Sub-Category
- Sales
- Profit

Data Cleaning & Preprocessing

Data preprocessing was performed using Python and Pandas.

Steps included:

- Checking for missing values
- Removing duplicate records
- Converting date columns to proper datetime format
- Creating additional columns such as Month and Year for time-based analysis

Exploratory Data Analysis

Exploratory data analysis was performed to identify important patterns in the dataset.

The analysis focused on:

- Sales performance by region
- Monthly sales trends
- Top-selling product sub-categories
- Category-wise revenue distribution

Dashboard

An interactive dashboard was built using Microsoft Power BI to visualize the results.

Dashboard features include:

- Total Sales KPI
- Total Profit KPI
- Sales by Region
- Monthly Sales Trend
- Top Selling Products
- Category-wise Sales Distribution
- Interactive filters for Region, Category, and Order Date

Key Insights

Some important insights obtained from the analysis:

- The West region generated the highest revenue among all regions.
- Technology products contributed the highest sales.
- Sales showed noticeable growth during certain months, indicating seasonal demand.

Future Improvements

Possible future improvements for the project include:

- Adding advanced Power BI visuals and DAX measures
- Implementing predictive sales forecasting
- Integrating multiple datasets for deeper business analysis
